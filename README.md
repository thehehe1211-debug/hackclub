# ten.375.studio mirror

Static copy of the site. 20 files, ~2 MB total (GitHub limits: 100 MB per file, 100 files per browser upload; both fine here).

## Upload
1. Create a new repo on GitHub.
2. Click "uploading an existing file", drag in the CONTENTS of this folder (including `.nojekyll`, which may be hidden), commit.
3. Settings -> Pages -> Deploy from branch -> `main` / root.

For the site's `/_next/...` paths to work, name the repo `<username>.github.io` (root-hosted) or use a custom domain.
